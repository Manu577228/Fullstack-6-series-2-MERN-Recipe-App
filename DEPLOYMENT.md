# Deploy the MERN Recipe App

This repository contains a Create React App frontend and a Node/Express API.
The API requires MongoDB Atlas; Redis caching is optional.

## Security first
Both `recipe-app-backend/.env` and `recipe-app-frontend/.env` were previously committed.
They are removed in this deployment change, but **git history still retains their contents**.
Rotate any real MongoDB passwords, JWT signing secrets, Redis credentials or other keys
that were ever committed. Do not reuse the old credentials. Do not paste secrets into git.

## 1. Create MongoDB Atlas database
Create a cluster, database user and a connection string. Allow network access from
the Render service (Atlas network access configuration); restrict access where practical.
Keep `MONGO_URI` secret.

## 2. Deploy both services on Render
1. Open https://dashboard.render.com/blueprints and create a new Blueprint.
2. Connect this GitHub repository. Select the branch containing `render.yaml`
   (usually `master` after merging the deployment PR).
3. Supply the required Blueprint environment variables:
   - API `MONGO_URI`: Atlas connection string
   - API `CLIENT_ORIGIN`: the exact HTTPS frontend origin, e.g.
     `https://manu-recipe-app.onrender.com`
   - Static frontend `REACT_APP_API_URL`: the HTTPS backend origin, e.g.
     `https://manu-recipe-api.onrender.com`
   - `JWT_SECRET`: auto-generated by Render
4. Review service names and final hostnames before submitting. If Render assigns
   different hostnames, correct `CLIENT_ORIGIN` and `REACT_APP_API_URL` in
   their respective Render service environment settings and redeploy the static site.
5. API: `https://<api-host>/health` must return `{"ok":true}`.
6. Open the frontend and test registration, login, create, edit, save and delete.
   Also refresh deep routes (e.g. `/auth`) to verify the SPA rewrite.

## Local development
- Backend: `cd recipe-app-backend && cp .env.example .env && npm ci && npm run dev`
- Frontend: `cd recipe-app-frontend && cp .env.example .env && npm ci && npm start`
- Put real development-only values in untracked `.env` files.

## Notes
- The frontend's `REACT_APP_API_URL` is embedded at build time, not runtime.
  Changing it requires a frontend rebuild/redeploy.
- The backend uses Render's `PORT` automatically, with local fallback 3001.
- Redis is disabled when `REDIS_URL` is absent.
- Render-hosted services and MongoDB Atlas may incur charges or suspend at idle,
  depending on the selected plans.
